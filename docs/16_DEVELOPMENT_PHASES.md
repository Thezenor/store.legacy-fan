# 16 — Fases de desarrollo

## Fase 0 — Planificación

- Leer documentación.
- Detectar contradicciones.
- Aprobar arquitectura.
- Definir base de datos.
- Definir diseño.

## Fase 1 — MVP comercial

- Landing Legacy Fan Club.
- Prime/Prestige.
- Registro/login.
- Reserva 50 € / 50 $.
- Pago completo PayPal.
- Stripe preparado/desactivado.
- Fases globales.
- Cuenta usuario.
- Superadmin básico/completo.
- Numeración socios.
- Productos incluidos.
- Upsell segunda moneda.
- Estados básicos.
- Emails esenciales.
- SEO básico.
- Mobile-first.

## Fase 2 — Store completa

- Carrito.
- Compra monedas sueltas.
- Productos independientes.
- Drops privados.
- Cupones avanzados.
- Shipping avanzado.
- Integraciones transportistas.

## Fase 3 — Comunidad y contenido

- Contenido privado.
- Blog activo.
- Votaciones diseños.
- YouTube/Discord/Telegram mejor integrados.
- Eventos.

## Fase 4 — Escalado

- Automatizaciones avanzadas.
- DHL/UPS/FedEx.
- Multiwarehouse si aplica.
- Analytics avanzado.
- Afiliados/influencers.
