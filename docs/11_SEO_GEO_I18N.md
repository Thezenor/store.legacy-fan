# 11 — SEO, GEO e internacionalización

## Obligatorio

- Mobile-first.
- Páginas rápidas.
- SEO técnico desde inicio.
- GEO por países/regiones.
- Multiidioma ES/EN/FR/IT en web pública.
- Admin editable en ES/EN.

## SEO técnico

- URLs limpias.
- Sitemap automático.
- robots.txt.
- Canonical.
- Hreflang.
- Open Graph.
- Twitter/X cards.
- Schema.org:
  - Organization
  - Product
  - Offer
  - FAQPage
  - BreadcrumbList
  - Article para blog
- Metadatos editables desde admin.
- Imágenes optimizadas.
- Lazy loading.
- Core Web Vitals.

## GEO

Preparar estructura para contenidos por región:

- España
- Europa
- Estados Unidos
- LATAM
- Oriente Medio
- Asia

No inventar promesas legales por país. Textos legales variables.

## Blog / noticias

Dejar preparado aunque no esté activo inicialmente.

- estado borrador/publicado
- imagen destacada
