# 09 — Superadmin `/lf-admin`

## Principio

El superadmin puede modificar todo.

## Roles

Roles configurables desde superadmin. Roles iniciales recomendados:

- Superadmin
- Admin
- Marketing
- Soporte
- Logística
- Finanzas
- Editor contenido

Permisos granulares por módulo.

## Configuración del sistema

- datos empresa
- datos fiscales
- facturación
- impuestos
- país base
- moneda principal
- pasarelas pago
- emails administrativos
- envíos
- zonas
- fases globales
- fecha lanzamiento
- textos legales
- FAQ variables
- SEO/GEO
- idiomas
- modo mantenimiento
- logs

## Fases globales

Configurar:

- nombre
- fechas inicio/fin
- precio Prime EUR/USD
- precio Prestige EUR/USD
- envío gratis sí/no
- países con envío gratis
- texto promocional
- estado activo/inactivo

Cambian automáticamente por fecha, pero superadmin debe poder forzar estado.
