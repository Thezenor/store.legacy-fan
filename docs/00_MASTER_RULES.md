# 00 — Reglas maestras del proyecto

## Identidad

- Nombre público: **Legacy Fan**
- Dominio de trabajo: **store.legacy-fan.com**
- El concepto **Early Collector no existe** y debe eliminarse/redirigirse.
- La oferta pública se estructura como **Legacy Fan Club** con dos planes:
  - Legacy Prime Club
  - Legacy Prestige Club
- Founders Circle queda como nivel futuro/privado para inversores o invitación.

## Principios

- Mobile-first obligatorio.
- SEO/GEO desde el inicio.
- Modo oscuro por defecto.
- Botón para alternar a modo claro.
- Cuenta obligatoria para reservar o comprar.
- Número de socio solo para membresías pagadas completamente.
- Comprar monedas sueltas en el futuro no asigna número de socio si no hay club activo.
- Todo precio, fase, fecha, descuento, caducidad, texto legal, FAQ y configuración comercial debe ser variable desde superadmin siempre que sea posible.

## Rutas

- Superadmin: `/lf-admin`
- Panel usuario/socio: `/account`
