# 07 — Envíos y estados

## Envíos

- Venta mundial.
- Envío gratis en Fase 0 solo para España.
- Zonas, países, precios y reglas configurables desde superadmin.
- Envíos parciales permitidos.
- Tracking manual en fase inicial.
- Dejar preparado para DHL y otras integraciones futuras.

## Productos pendientes

Mystery Boxes:
- Se indicará que se enviarán más adelante, cuando Legacy Fan reciba la mercancía.
- Texto recomendado:
  > Las Mystery Boxes se enviarán posteriormente, una vez recibida y validada la mercancía correspondiente.

Monedas/productos:
- Cada producto tiene fecha de lanzamiento y estado.
- Pueden estar incluidos en clubes o disponibles de forma independiente.
