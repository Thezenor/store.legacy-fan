# 17 — Checklist QA

## Registro

- Email único.
- Login existente.
- Registro nuevo.
- Validación términos.
- Contraseña segura.

## Reserva

- Reserva 50 EUR.
- Reserva 50 USD.
- No asigna número.
- Panel muestra pendiente.
- Caduca según regla.
- Reembolso dentro de plazo.

## Pago completo

- Paga Prime completo.
- Paga Prestige completo.
- Paga restante tras reserva.
- Asigna LF-000101.
- No usa números 1–100.
- Crea productos incluidos.
- Activa puntos.
- Activa referidos si aplica.

## Upsell

- Muestra segunda moneda.
- Aplica descuento correcto.
- Solo una adicional.
- Disponible hasta lanzamiento.
- Se añade al pedido.

## Admin

- Cambiar fases.

- Cambiar fecha lanzamiento.
- Crear producto.
- Marcar moneda inaugural.
- Asignar número manual.
- Editar legal.
- Editar SEO.
- Enviar email test.
