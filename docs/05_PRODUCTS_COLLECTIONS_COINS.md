# 05 — Productos, colecciones y monedas

## Colecciones

Todos los productos estarán dentro de una colección.

Una colección puede tener estado:

- borrador
- próxima
- activa
- agotada
- oculta
- privada/drop

Una colección puede tener varios productos:

- monedas de plata
- monedas de cobre
- Mystery Boxes
- productos físicos
- productos digitales
- membresías relacionadas
- drops privados

## Productos

Cada producto debe poder configurarse con:

- nombre
- slug
- colección
- descripción
- imágenes/renders
- precio USD
- precio EUR
- premium configurable
- valor spot/base si aplica
- fecha de lanzamiento
- disponible/no disponible
- visible/oculto
- incluido en Prime
- incluido en Prestige
- moneda inaugural seleccionable
- compra adicional
- drop oculto/privado
- certificado requerido
- QR autenticidad
- estado logístico

## Moneda inaugural

- Algunos productos podrán marcarse como moneda inaugural.
- Si hay 2 o más monedas inaugurales, el cliente puede elegir una como principal.
- La elección no se puede cambiar después de pagar.
- Antes de finalizar compra se mostrará upsell para añadir una segunda moneda con descuento.
- La segunda moneda se puede añadir hasta antes del lanzamiento.
- Debe mostrarse como limitada.
- De momento solo se puede añadir 1 moneda adicional con descuento.
- Si en el futuro hay más de 2 monedas, se deja preparado para ampliar.

## Upsell segunda moneda

Debe aparecer:

- antes de finalizar checkout
- en panel durante ventana habilitada
- con imagen
- nombre
- precio normal
- descuento correspondiente al club
- precio final
- texto de urgencia/limitación
- botón añadir

## Certificados

- Cada producto certificable tendrá certificado físico.
- El socio tendrá copia digital en el panel.
- QR único para verificación/autenticidad.
- Certificación nominal para Prestige según documentación.
