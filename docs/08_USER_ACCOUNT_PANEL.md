# 08 — Panel de usuario `/account`

## Cuenta con reserva

Usuario con reserva ve:

- estado “Reserva pendiente de pago completo”
- importe pagado
- importe restante
- botón pagar restante
- fecha límite/caducidad
- club sugerido o selector de club al completar pago
- avisos de que no tiene número de socio hasta pago completo
- no acceso completo a Telegram/Discord
- no ventajas activas

## Socio activo

Usuario con pago completo ve secciones organizadas:

### Resumen

- nombre
- club activo
- número de socio
- estado membresía
- fecha inicio
- fecha fin
- ventajas principales

### Mi membresía

- Prime/Prestige
- upgrade disponible
- renovaciones ocultas por ahora
- productos incluidos

### Mis productos

- productos incluidos
- estado individual
- tracking
- certificados digitales
- QR autenticidad

### Segunda moneda

- oferta de segunda moneda si está en ventana activa
- imagen
- precio
- descuento
- botón comprar

### Puntos / saldo

- saldo disponible
- saldo pendiente
- saldo usado
- caducidad
- histórico

### Referidos

- código
- enlace
- modalidad recompensa
- estadísticas
- saldo generado

### Comunidad

- acceso Telegram
- acceso Discord
- newsletter
- canal YouTube exclusivo
- contenido privado si aplica

### Pedidos y facturas

- reservas
- pagos
- pedidos
- facturas
- comprobantes

### Perfil

- datos personales
- dirección
- país
- idioma
- contraseña
- preferencias comunicación
