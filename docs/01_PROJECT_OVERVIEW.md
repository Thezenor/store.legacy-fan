# 01 — Visión general del proyecto

Legacy Fan es una plataforma de coleccionismo premium en metales preciosos, arte, comunidad y lanzamientos limitados.

La primera fase se centra en vender membresías anuales:

## Legacy Prime Club

Entrada accesible al universo Legacy Fan.

## Legacy Prestige Club

Acceso premium con pieza inaugural de 3 oz plata .999, pieza de 1 kg cobre .999, Mystery Boxes y beneficios superiores.

## Store

`store.legacy-fan.com` debe funcionar como:

- Landing de conversión.
- Store inicial de membresías.
- Sistema de reservas.
- Checkout de pago completo.
- Panel de socio.
- Superadmin.
- Base futura para venta de monedas sueltas, drops y tienda completa.

## Web principal

El dominio principal `legacy-fan.com` puede existir como web corporativa, pero este proyecto se centra en `store.legacy-fan.com`.

## Redirección

Cualquier ruta antigua de Early Collector debe redirigirse a la nueva landing del club, por ejemplo:

- `/early-collector` → `/club` o home de store.
